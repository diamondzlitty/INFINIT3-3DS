# Universal-Updater / Universal-DB Plan

Goal: expose INFINIT3 TERMINAL and INFINIT3 NEWS as two independently selectable applications in Universal-DB while hosting their source and GitHub Release assets in the same INFINIT3-3DS repository.

Before submission we will prepare:

- separate app title and description metadata
- separate icons
- separate screenshots
- stable .3dsx release asset names
- install destinations
- version information
- license information
- categories and supported system metadata
- release/update validation on real hardware

Do not submit either application until its public release build has passed hardware QA.
