# Release Contract

INFINIT3 uses one GitHub repository containing two independently installable Nintendo 3DS applications.

## Stable release asset names

- `INFINIT3_TERMINAL.3dsx`
- `INFINIT3_NEWS.3dsx`

Future optional assets:

- `INFINIT3_TERMINAL.cia`
- `INFINIT3_NEWS.cia`

Debug ELF files are not public release assets.

Version tags will use semantic-style release tags such as `v0.1.0`.

Both applications may advance internally at different milestone rates while remaining part of the same INFINIT3 suite release.
